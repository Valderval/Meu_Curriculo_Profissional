## 🗺️ COMO USAR ESTE ARQUIVO NO FUTURO

1. **Sempre que fizer um novo show, grave um novo álbum ou participar de um evento:** 
   - Volte aqui, crie a data do dia, preencha os campos e faça o commit no Git.

2. **Quando precisar preencher um edital (ex: Lei de Incentivo):**
   - Abra o arquivo, pesquise pelas palavras-chave (ex: "baterista", "produtor", "2025") e **copie e cole** os parágrafos inteiros direto para o arquivo da versão sob demanda.

3. **Para criar seu Currículo de 1 página:**
   - Pegue apenas os eventos dos últimos 3 anos e reduza cada descrição para UMA linha.

4. **Para atualizar sua Bio curta:**
   - Vá na seção "DESTAQUES", pegue os 2 primeiros itens e monte uma frase.
